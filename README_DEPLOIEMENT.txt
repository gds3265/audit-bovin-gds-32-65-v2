PUBLICATION GITHUB PAGES
1. Décompresser ce ZIP sur l'ordinateur.
2. Ouvrir le dépôt GitHub destiné à l'application.
3. Add file > Upload files.
4. Importer TOUS les fichiers contenus dans le dossier décompressé.
5. Vérifier que index.html se trouve directement à la racine.
6. Commit changes.
7. Attendre 1 à 3 minutes.
8. Ouvrir le lien GitHub Pages avec ?v=10.1 à la fin.

TESTS À EFFECTUER
- Ajouter une exploitation.
- Fermer/réouvrir la page : l'exploitation doit rester.
- Créer une visite.
- Modifier la visite et vérifier le journal.
- Exporter la visite JSON.
- Exporter la sauvegarde complète.
- Tester la restauration JSON en navigation privée ou sur un autre appareil.
